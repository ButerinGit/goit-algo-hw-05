# Звіт по ДЗ №5

## Мета роботи

Порівняти ефективність алгоритмів пошуку підрядка (Боєра–Мура, Кнута–Морріса–Пратта, Рабіна–Карпа) на різних текстах.

## Використані дані

* `data/art.txt`
* `data/art2.txt`

## Результати бенчмарку

| Файл     | Підрядок (існує) | Підрядок (немає)             | Найшвидший (існує) | Найшвидший (немає) |
| -------- | ---------------- | ---------------------------- | ------------------ | ------------------ |
| art.txt  | алгоритмів       | фантастичне_слово_якого_нема | KMP                | Boyer-Moore        |
| art2.txt | алгоритмів       | фантастичне_слово_якого_нема | KMP                | Rabin-Karp         |

## Висновки

* Для пошуку існуючого підрядка найкраще показав себе **KMP**.
* Для пошуку відсутнього підрядка швидшими виявились **Boyer-Moore** та **Rabin-Karp** (залежно від файлу).
* Загалом, **KMP** є стабільно ефективним при знаходженні збігів, тоді як Boyer-Moore інколи краще справляється з пошуком відсутніх підрядків.

## Додатково

Результати зберігаються у форматі JSON (`results.json`) і можуть бути використані для побудови графіків чи детальнішого аналізу.
